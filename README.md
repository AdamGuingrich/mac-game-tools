# Mac Game Tools — downloads

Installers for **Mac Game Tools**, a small Windows app that edits your game files safely. For **Satisfactory** it sets
every conveyor belt, lift, pipe and pump in a **save** or in **blueprints** to one tier, fixes pieces that copy as the
wrong tier, and writes **new** files (your originals are never changed). It can send the new files straight to the app
on another PC on the same network, and a Claude session on the same PC can use it (MCP: *Use with Claude* in the app).

**Install:** download `MacGameTools-Setup-<version>.exe` from [Releases](../../releases/latest) and run it.
It installs for your Windows user only (no admin prompt). Windows SmartScreen may warn about an unknown publisher:
choose *More info → Run anyway*.

**Update:** the app checks this page for new versions and offers *Restart to update*. Every update is signed; the app
refuses one that is not.

**Coming from Mac Satisfactory Editor?** Mac Game Tools replaces it (new name, so it does not update itself to this
app). Install Mac Game Tools, which takes over its settings, then quit and uninstall Mac Satisfactory Editor.
